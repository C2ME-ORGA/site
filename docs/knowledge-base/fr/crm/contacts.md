# Contacts

Les contacts sont les interlocuteurs physiques d'un compte : conducteur de
travaux, acheteur, architecte, assistante…

## Ajouter un contact

1. Ouvrir la fiche du compte.
2. Aller dans l'onglet **Contacts**.
3. Cliquer sur **Nouveau contact**.
4. Renseigner civilité, prénom, nom, fonction, e-mail et téléphones.
5. Enregistrer.

Un contact est toujours rattaché à un compte : il n'existe pas de contact
orphelin dans le CRM.

## Champs utiles

| Champ | Usage |
| --- | --- |
| **Fonction** | Rôle dans l'entreprise, utile pour choisir le bon interlocuteur. |
| **E-mail** | Utilisé pour les envois depuis la boîte de réception. |
| **Téléphone / Mobile** | Repris dans les actions rapides du mode terrain. |
| **Contact principal** | Met en avant l'interlocuteur de référence sur la fiche compte. |
| **Notes** | Préférences, horaires, consignes d'accès. |

## Actions rapides

Depuis la fiche du compte ou le mode terrain :

- **Appeler** ouvre le composeur du téléphone ;
- **Envoyer un SMS** prépare un message ;
- **Écrire un e-mail** ouvre la composition préremplie ;
- **Ouvrir dans Plans** lance l'itinéraire vers l'adresse.

## Données personnelles (RGPD)

Deux actions réservées aux administrateurs sont disponibles sur un contact :

- **Exporter les données (RGPD)** : JSON contenant le contact, son compte, les
  affaires, devis, activités et e-mails liés.
- **Anonymiser** : efface nom, coordonnées et notes, tout en conservant
  l'historique commercial. L'opération est journalisée sans recopier les valeurs
  effacées.

> Une demande d'exercice des droits doit être traitée par un administrateur.
> Voir la page **RGPD et conservation**.

## Bonnes pratiques

- Un contact par personne physique : ne pas saisir « Service achats » comme
  contact.
- Mettre à jour l'e-mail dès qu'un interlocuteur change de poste, sinon les
  envois rebondissent et faussent le suivi.
- Marquer un seul contact principal par compte.
