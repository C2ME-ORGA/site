# Activités

Une activité trace un événement du suivi commercial : appel, e-mail,
rendez-vous, visite, relance, note ou tâche. C'est l'historique opérationnel des
fiches.

## Créer une activité

1. Menu **CRM › Activités & relances**, puis **Nouvelle activité**.
2. Choisir le **type**.
3. Renseigner l'**objet** et, si possible, rattacher le **compte**, le
   **contact**, l'**affaire** ou le **devis**.
4. Indiquer la date de réalisation ou l'**échéance**.
5. Décrire le contenu et le **résultat**.
6. Enregistrer.

Les activités planifiées apparaissent aussi dans le **calendrier** et, pour le
commercial concerné, dans le flux ICS personnel.

## Champs

| Champ | Usage |
| --- | --- |
| **Type** | Appel, E-mail, Rendez-vous, Visite, Relance, Note ou Tâche. |
| **Assigné à** | Commercial responsable ; conditionne la visibilité. |
| **Réalisée le** | Date réelle de l'échange. |
| **Échéance** | Date prévue pour une tâche ou une relance. |
| **Rappel** | Déclenche une notification avant l'échéance. |
| **Résultat** | Conclusion courte : « à relancer la semaine prochaine », « devis demandé ». |
| **Photos** | Jusqu'à 5 photos par activité (voir ci-dessous). |

## Photos

Le mode terrain permet de joindre des photos prises sur place :

- 5 photos maximum par activité ;
- 5 Mo maximum après compression ;
- formats JPEG après compression automatique (1600 px de côté maximum) ;
- stockage privé, lecture uniquement via une route authentifiée.

Les photos sont visibles dans la fiche de l'activité et disparaissent avec elle
ou lors de la purge de rétention.

## États

- **Planifiée** : échéance à venir, pas encore réalisée.
- **En retard** : échéance dépassée, non terminée.
- **Terminée** : réalisée, avec une date de fin renseignée.

Le filtre **Priorité terrain** remonte en tête les activités du jour et les
retards.

## Relances liées

Une activité de type **Relance** avec une échéance alimente la page
**Relances**, qui envoie des rappels la veille à 17:00 et le jour même à 08:00.

## Suppression et rétention

Les activités supprimées partent en corbeille : la suppression définitive est
journalisée. Les activités anciennes sont purgées selon la durée de conservation
configurée (voir **RGPD et conservation**).
