# Recherche globale

La page **CRM › Recherche globale** interroge en une seule fois les comptes des
trois carnets, les contacts, les affaires et les devis.

## Utilisation

1. Saisir au moins deux caractères dans le champ de recherche.
2. Les résultats sont regroupés par type, avec le nombre de correspondances.
3. Cliquer sur un résultat ouvre la fiche correspondante.

La recherche ignore la casse : « DUPONT », « dupont » et « Dupont » donnent le
même résultat.

## Filtres

- **Type** : comptes, contacts, affaires, devis.
- **Carnet** : restreindre aux prescripteurs, industriels ou entreprises du
  bâtiment.

Les groupes de résultats peuvent être repliés ; le bouton **Réinitialiser**
efface la recherche et les filtres.

## Scoping

Un commercial ne voit que les résultats des comptes dont il est le référent.
Les administrateurs voient tout. La recherche ne contourne jamais les policies.

## Différence avec la recherche de barre latérale

La barre de recherche Filament (raccourci clavier) cherche dans la ressource
courante. La **Recherche globale** est inter-carnets et inter-objets : c'est
l'outil à utiliser quand on ne sait pas dans quelle liste se trouve la fiche.
