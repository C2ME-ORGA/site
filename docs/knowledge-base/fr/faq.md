# Questions fréquentes

## Je ne vois pas un compte que je connais

Un commercial ne voit que les comptes dont il est le **référent**. Deux causes
possibles :

- le compte appartient à un collègue : demander le transfert à un
  administrateur ;
- le compte est dans un autre carnet, et le filtre de la liste le masque.

Utiliser la **Recherche globale** pour vérifier l'existence de la fiche.

## Je ne retrouve pas un devis

- Vérifier le filtre de **statut** : les devis classés et refusés sont souvent
  masqués.
- Utiliser la **Recherche globale** par référence ou par objet.
- Vérifier la période d'émission.

## Puis-je modifier un devis accepté ?

Techniquement oui, mais cela fausse le suivi. Préférer créer une révision ou un
nouveau devis, et classer l'ancien. Chaque transition de statut est journalisée.

## Pourquoi mon activité n'apparaît-elle pas dans le calendrier ?

Le calendrier affiche les activités **planifiées et non terminées**. Vérifier :

- que l'**échéance** est renseignée ;
- que l'activité n'est pas marquée terminée ;
- qu'on est bien l'utilisateur assigné.

## Le mode terrain ne se synchronise pas

1. Vérifier la connexion réseau.
2. Regarder l'onglet **Données** : les opérations en attente et les erreurs y
   sont listées.
3. En cas de session expirée, se reconnecter : la file est conservée.
4. En cas de conflit, choisir entre version locale, version serveur ou fusion
   champ par champ.

## Où est passée mon URL de calendrier ?

L'URL du flux ICS est un secret. Elle est disponible dans **Calendrier ›
S'abonner**. Si elle a été partagée par erreur, utiliser **Régénérer** et
reconfigurer les abonnements.

## J'ai supprimé une fiche par erreur

Les suppressions passent par une corbeille. Un administrateur peut restaurer la
fiche depuis la liste (filtre « supprimés »). La suppression définitive, elle,
n'est pas réversible.

## Un e-mail n'arrive pas dans le CRM

- Vérifier que la boîte est **active** et que la dernière synchronisation est
  récente.
- Vérifier le dossier côté serveur : seuls les messages de la boîte de réception
  sont relevés.
- Consulter la **Visionneuse de logs** pour une erreur IMAP.

## Comment changer mon mot de passe ?

Depuis **Profil**. En cas d'oubli, demander à un administrateur de réinitialiser
le mot de passe.

## Qui peut exporter ou anonymiser un contact ?

Uniquement les administrateurs. Ces deux actions sont journalisées.

## Comment proposer une amélioration de cette documentation ?

Les articles sont des fichiers Markdown versionnés avec l'application. Une
correction se fait par une demande de modification à l'équipe technique, en
précisant l'article et le passage concerné.
